Vibe PCB converts 21 KiCad 10.0.3 library footprints into JSON pad/body/courtyard geometry. Rounded SMD pads in this bundled collection are conservatively represented as rectangles. Each package retains the original source URL, SHA-256 and license. The conversion script is included. Conversion code is MIT; converted library data is CC-BY-SA-4.0 with the exception. No manufacturer STEP models are included.
